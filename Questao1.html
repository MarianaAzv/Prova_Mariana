O processo começa quando o ususario digita em seu navegador uma url, assim inicio o processo. Pela URL o computador do cliente(ususario) identifica o dominio do site e endereço para onde precissa enviar a sua requisiçao para acessar aquele site, assim inicializa a comunicaçao com o servidor enviando uma http request, atraves dessa comunicaçao é verificado por um protocolo se o site esta funcionando corretamente e se sera possivel acessa-lo, nessa requisição alem dele enviar um pedido para acessar determinado conteudo ele tambem manda o seu IP que ajudam o servidor saber para onde prescisa responder, quando o servidor responde manda um http response ou https.
