O processo começa quando o ususario digita em seu navegador uma url, assim inicio o processo o computador do cliente(ususario),analisa a url pois ela é como um endereço para onde precissa enviar a sua requisiçao para acessar aquele site, assim manda um http request para o servidor(contido no endereço), alem dele enviar um pedido para acessar determinado conteudo ele tambem manda o seu ip e outras informaçoes que ajudam o servidor saber onde é necessario enviar a sua resposta(http response ou https), porem ele vai enviar o site se o servidor estiver funcionando corretamente,senao ele envia uma resposta com um codigo que explica o erro que esta acontecendo.
