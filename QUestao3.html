O css foi criado para estilizar o texto ou um documento feito em html, assim para ele nao estilizar o texto inteiro conseguimos estilizar algumas partes do texto so usando seletoores como por exemplo se eu quiser estilizar um paragrafo que tem um id = pid com a cor rosa e uma fonte de tamenho diferente, eu coloco #pid como seletor para estilizar somente este paragrafo e abro chaves, e dentro dessa chave eu coloco um codigo/metodo como por exeplo se eu quiser colocar rosa, background-color: com o valor depois dos dois pontos rosa ficando background-color:rosa; o rosa sendo o meu valor.
