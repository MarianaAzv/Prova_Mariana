O css foi criado para estilizar o texto ou um documento feito em html, assim para ele nao estilizar o texto inteiro conseguimos estilizar algumas partes do texto so usando seletores, por esses seletores definimos qual tag queremos estilizar, podemos estilizar pela tag, podemos estilizar um especifico pelo seu id(#), podemos estilizar usando a class(.) e entre outros. Dentro das chaves é digitado um codigo/variavel para definir quais estilizacoes ira acontecer e em seguida irei definir um valor para essa variavel. Exemplo: Ter um paragrafo da cor rosa, escolhemos o seletor

se ele conter um id colocamos o seu id para ficar mais especifico para a estilizaçao e depois colocamos a variavel background-color : e a sua variavel pink
